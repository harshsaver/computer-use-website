# December landing page

The public landing page for [december.dev](https://december.dev).

December is a long-term Wega Labs dream: a little world whose artificial
residents remember, build, form relationships, change, and keep living while no
one is watching. The deeper research plan remains available, but the public page
leads with the world and the feeling of returning to lives that continued.

## Local development

```bash
npm install
npm run dev
```

The site is deliberately static: `index.html`, `styles.css`, `script.js`, and
project-owned assets. Pushing `main` deploys the site through the existing
Vercel project.

The former human-participant request and public GitHub life-history flow have
been removed. Calls to action now invite questions and ideas only. Human-persona
intake remains outside the current project scope.

## Status

December is in its design and audit phase. The rendered copy follows the current
[landing-page brief](../LANDING-PAGE-BRIEF.md) and keeps the boundary from the
[lab charter](../wiki/18-lab-charter-and-research-program.md): the world does not
exist yet, its future residents are software, and the distant hope is a compass
rather than evidence or a promise.
